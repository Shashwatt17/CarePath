# CarePath continuation rules

Read PROJECT_STATUS.md first, then inspect the existing source before editing.
The user specification summarized there is authoritative. Implement only the requested phase.
Do not assume schema/dependencies/docs prove a product feature exists. Do not regenerate working
components. Append Flyway migrations once existing migrations have been applied. Never invent
medical facts or evaluation metrics, expose credentials, or use real patient data in fixtures.
Record implementation, exact verification results and unresolved issues at the end of each phase.
Keep API ownership checks, provenance and uncertainty compatible with ARCHITECTURE.md/SECURITY.md.
No sub-agent delegation is requested by these instructions.
